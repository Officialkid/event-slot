# Notifications

Notifications keep attendees informed and reduce support load for organizers.

## Event Notification Triggers

- Registration confirmed
- Waitlist joined
- Waitlist promoted
- Reminder before event
- Event update from organizer
- Post-event follow-up

## Template Strategy

Use concise, action-driven templates:

1. Put critical action in the first line.
2. Include local timezone details.
3. Add direct links to attendee actions.
4. Keep fallback language for low-bandwidth users.

## Reliability Controls

- Automatic retries for transient provider failures
- Delivery logs per attendee action
- Optional dual-channel fallback for high-priority updates

## Operational Tip

Run notification dry-runs in staging before every high-volume launch.
