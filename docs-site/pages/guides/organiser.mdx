# Organiser Guide

> [!NOTE]
> This guide matches current organiser flows in the EventSlot dashboard and event APIs.

## Getting started as an organiser

1. Sign up or sign in at /signin.
2. Complete onboarding prompts.
3. Go to /dashboard.
4. Create your first event from /create.

## Create your first event (step by step)

### Step 1: Open event creation

From dashboard, click Create Event.

### Step 2: Fill core fields

- title
- optional description
- optional deadline
- optional capacity
- registration questions

### Step 3: Save and publish

Once created, EventSlot gives you a public slug link.

Screenshot guidance for docs readers:

- screen 1: dashboard create action
- screen 2: event form with question builder
- screen 3: event summary with shareable link

## Capacity and registration settings

Set capacity based on venue or operational limit. If capacity is reached, new registrations move to waitlist automatically.

## Publish and share event link

Share the public slug URL with attendees. Attendees do not need EventSlot accounts for standard registration.

## Monitor registrations in dashboard

Use /dashboard/events and event-level pages to review:

- confirmed registrations
- waitlist pressure
- near-capacity risk
- recent activity

## Manage the waitlist

When needed, increase capacity from event controls. EventSlot promotes queued users in FIFO order.

## Cancel or edit an event

Use event settings and archive/close controls for lifecycle management. Operational updates propagate through organiser surfaces and notification channels.
