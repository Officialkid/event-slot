# Launch Checklist

Use this checklist before opening registrations for high-demand events.

## Product Readiness

- Event details validated with stakeholders
- Capacity and waitlist thresholds approved
- Registration form reviewed for data minimization
- Notification templates approved

## Technical Readiness

- API keys rotated and scoped
- Monitoring dashboards configured
- Error alert channels tested
- Backup and rollback plan documented

## Dry Run

1. Execute full attendee flow in staging.
2. Simulate sold-out scenario.
3. Validate waitlist promotion workflow.
4. Confirm check-in and reporting visibility.

## Go-Live Controls

- Assign incident commander
- Enable launch war room communication channel
- Track registration conversion every 15 minutes during initial traffic spike
