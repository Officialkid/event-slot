# Getting Started

This section takes you from account setup to your first live event in production.

## In This Section

- [Quickstart](./quickstart): Create an event, configure registration, and go live.
- [Platform Architecture](./architecture): Understand EventSlot's core data and runtime model.

## Prerequisites

- An EventSlot organizer account
- Access to your team's domain for branded pages (optional)
- Paystack merchant account (for paid tickets)
- Google Workspace account (if enabling calendar sync)
