# Growth Loops

This page documents the primary acquisition and retention loops that can compound adoption for EventSlot.

## Organic growth loop

Each event link acts as distribution. Public registration surfaces can include EventSlot branding signals, which create repeated exposure with every event share.

## Organiser flywheel

1. organiser creates event
2. attendees register through EventSlot link
3. attendees experience smoother registration and waitlist flow
4. some attendees become future organisers
5. organiser demand grows with proven reliability

## Word-of-mouth in community ecosystems

EventSlot is well-suited for campus, church, and community event networks where recommendations spread through trusted groups.

## Network effect model

More organisers create more events.
More events bring more attendees.
More attendees create more future organisers.

This flywheel is strongest when operational reliability is high under demand spikes.
