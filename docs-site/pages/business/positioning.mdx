# Market Positioning

This page explains EventSlot's current market narrative, target segment focus, and differentiation strategy.

## Target segment

Primary target is African SME and community event organisers who need reliability, speed, and clarity for slot-limited events.

## Brand position

EventSlot is positioned between:

- basic form collection tools
- complex ticketing marketplace platforms

It offers operational automation without heavy marketplace complexity.

## Core marketing messages

- registration that does not break when demand spikes
- automatic waitlist progression with less manual work
- dashboard visibility for organisers who need real control
- Africa-first operational choices in billing and deployment

## What EventSlot is not

- not a pure marketplace like Eventbrite
- not only a generic form tool
- not a heavy enterprise event suite by default
