## Platform at a glance

- **Status:** Pre-launch (as documented in the current system docs)
- **Stack:** Next.js, TypeScript, Neon PostgreSQL, Prisma, NextAuth.js, Paystack, Resend, Google Cloud Run
- **Primary market focus:** African event teams
- **Access model:** Core platform features are free; report file downloads are paid bundles
