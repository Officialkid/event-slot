# Endpoints

This reference covers the most common API operations.

## Events

### Create Event

```http
POST /v1/events
```

```json
{
  "title": "Nairobi Product Leadership Forum",
  "starts_at": "2026-07-20T09:00:00+03:00",
  "ends_at": "2026-07-20T16:00:00+03:00",
  "capacity": 300
}
```

### List Events

```http
GET /v1/events?status=published&limit=20
```

## Registrations

### Create Registration

```http
POST /v1/events/{event_id}/registrations
```

```json
{
  "first_name": "Amina",
  "last_name": "Odhiambo",
  "email": "amina@example.com",
  "phone": "+254700000000"
}
```

### Get Registration

```http
GET /v1/registrations/{registration_id}
```

## Waitlist

### Promote Waitlist Entry

```http
POST /v1/events/{event_id}/waitlist/{entry_id}/promote
```

### Reorder Waitlist Entry

```http
PATCH /v1/events/{event_id}/waitlist/{entry_id}
```

```json
{
  "priority_score": 88
}
```

## Health

```http
GET /v1/health
```

Returns service and dependency health signals for monitoring integrations.
