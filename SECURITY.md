# Security Policy

EventSlot handles event registration data, attendee contact details, tickets,
and organiser account access. Please report security issues privately.

## Reporting A Vulnerability

Email: eventslot.co@gmail.com

Include:

- A clear description of the issue.
- Steps to reproduce.
- Affected URL, route, or feature.
- Screenshots or proof-of-concept details if safe to share.
- Your contact email for follow-up.

Please do not open public GitHub issues for vulnerabilities involving account
access, attendee data, payment data, API keys, authentication, authorization, or
private event links.

## Response Target

We aim to acknowledge valid reports within 3 business days and provide a
remediation update as soon as the risk is understood.

## Scope

In scope:

- EventSlot web app and APIs.
- Authentication and authorization flaws.
- Ticket verification bypasses.
- Registration data exposure.
- Email, token, or invite-link security issues.

Out of scope:

- Social engineering.
- Denial-of-service testing without prior written approval.
- Spam or bulk email abuse.
- Physical attacks against user devices.
